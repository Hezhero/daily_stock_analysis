# 回测度量层诊断：两套记分板与现金拖累

> 日期：2026-10 ｜ 性质：诊断报告（文档交付，不含代码改动）
> 上游依据：`docs/specs/backtest_度量层重建/spec.md`（Round 1 + Round 2 已锁定）
> 数据来源：`result/指标契约_metric_contract_v1_20261017.md`、`result/backtest_胜率收益率提升规划_v2_20261017.md`、`docs/backtest-optimization-design.md`

## 0. 一句话结论

当前回测同时存在两块互相打架的记分板。信号级的 55.6% 胜率、322% 总收益、28.7% 年化、4.68 夏普，衡量的是一套无限资金、逐策略取事后最优持有期、且不逐日盯市的系统；资金约束下的真实组合只有 3.88% 的样本外 CAGR、43.67% 胜率、13.11% 最大回撤、0.423 夏普，并有 77.7% 的现金长期闲置。优化决策必须锚定组合级样本外风险调整记分板，胜率只能作为诊断项，不能当裁判。

## 1. 两块记分板

### 1.1 信号级记分板：不可下单

| 指标 | 数值 |
| --- | ---: |
| 平均胜率 | 55.6% |
| 平均总收益 | 322% |
| 平均年化 | 28.7% |
| 平均夏普 | 4.68 |

这套数字的口径有三处关键失真，任何一处都足以让它无法与真实账户对齐：

1. **无限资金、无跨策略竞争。** 每条策略曲线隐含独立满仓，没有持仓上限，也没有资金争用。真实账户最多 10 仓，信号之间必须抢同一笔现金。
2. **逐策略取事后最优持有期。** `best_period` 是在全 5 年样本上按平稳性挑选的 4 个持有期之一，头条胜率因此带上了样本内选优的乐观偏差。
3. **非逐日盯市。** `calc_portfolio_metrics` 把每笔收益按持有期均匀摊到每一天，持仓内的回撤路径被抹平，日收益序列被平滑，方差被低估，夏普虚高、回撤偏浅。头条指标还是 18 条高度相关策略曲线的无权重平均，其中 ensemble 与组件、趋势策略之间大量重复，既不是组合口径，也被趋势簇主导。

因此，55.6% 与 322% 不能解释为"策略本身很强"，只能解释为"在无限资金、事后选期、非盯市的口径下，信号的平均表现"。它描述的不是一个可以下单的系统。

### 1.2 组合级记分板：唯一可下单

| 指标 | 数值 |
| --- | ---: |
| 样本外 CAGR | 3.88% |
| 胜率 | 43.67% |
| 最大回撤 | 13.11% |
| 夏普 | 0.423 |
| 成交笔数 | 561 |
| 平均现金占比 | 77.7% |

口径为单一账户、最多 10 仓、T+1、`next_open` 入场、0.35% 往返成本加 ADV 分档滑点、逐日收盘盯市、252 交易日预热后的样本外窗口。样本区间为 2021-05-14 至 2026-10-16，共 1400 个交易日，21 个策略，`config_hash=5eea0519`。这是当前唯一能映射到真实资金约束的记分板。

同一批数据、同一段样本外窗口，年化从 28.7% 落到 3.88%，胜率从 55.6% 落到 43.67%，夏普从 4.68 落到 0.423。差距的主因不是市场变差，而是口径从"信号级、无限资金"切换到了"组合级、资金约束、逐日盯市"。

## 2. 根因

### 2.1 根因一：契约把可部署参数冻成了度量常量

《指标契约》§2.1 把 `min_resonance_families=2` 写进冻结参数表，`_portfolio_sim_config()` 在取值不为 2 时直接抛 `RuntimeError`。这意味着"权威度量层"不只是冻结了成本、盯市、PIT、去簇共振定义和入场口径，还冻结了一个本应被实验检验的部署参数。

同日完成的家族共振消融给出了相反的证据。两臂使用同一份代码、同一份数据，信号生成阶段完全一致（raw 18517、build 17915、各策略信号数逐项相同），差异全部来自家族过滤：

| 口径 | CAGR | 胜率 | maxDD | 闲置现金 |
| --- | ---: | ---: | ---: | ---: |
| ≥2 家族（当前冻结默认） | 3.88% | 43.67% | 13.11% | 77.7% |
| ≥1 家族（消融） | 8.19% | 45.23% | 10.48% | 67.8% |

四项指标全部由 ≥1 家族占优。补充数据同样同向：成交 561 笔增至 838 笔，夏普 0.423 升至 0.719，总收益 22.12% 升至 154.74%，平均持仓数 2.23 升至 3.22，成本拖累从 51.35% 升至 75.27%。成本拖累上升是成交增加的直接结果，但扣除成本后的收益、夏普和回撤仍然全面更好。

家族过滤是当前最大的信号削减项：build 17915 经去簇后只剩 9932，削减约 45%；≥1 家族下去簇后为 14548。把这样一个强削减项锁成不可触碰的度量常量，会使"度量层"测到的只是某个特定配置，而不是待检验的系统。更糟的是，当消融结果与冻结值冲突时，证据会呈现为"要么测的不是真正在跑的系统，要么自相矛盾"。

需要明确证据边界：该消融是全样本加单一预热后样本外口径，不是完整 WFO。按新的翻转门槛，它仍须通过池化样本外每信号 Δ 的日期分块 bootstrap，风险调整口径不劣于基线，才能翻转默认值。因此本轮不翻默认，只把 `min_resonance_families` 从"冻结常量"降级为"已登记待验证的实验参数"。

### 2.2 根因二：现金拖累是结构性的

`scripts/portfolio_sim.py` 第 439 行的仓位预算为：

```python
budget = min(equity_prev / cfg.max_positions, cash)
```

`max_positions` 默认是 10。也就是说，每一笔新仓位最多只能拿到前一日权益的十分之一，与信号质量、可用现金、波动率都无关。若当日合格信号少于 10 个，剩余资金只能留在现金里。平均持仓 2.23、平均现金占比 77.70%，正是这条固定 1/N 规则的直接结果。

这解释了一个容易误判的现象：继续加过滤器可以在信号级抬高胜率，却会让组合更饿。合格信号越少，能部署的仓位越少，现金拖累越重，组合 CAGR 越难提升。计划 v2 已经把这条列为风险项："过滤器可能饿死组合"。

因此，现金拖累不是"信号不够好"的副产品，而是仓位规则的结构性产物。即使把家族门槛降到 ≥1，闲置现金仍有 67.8%，说明单靠放宽共振并不能解决部署问题。真正未验证的高先验杠杆是资金部署感知仓位，而不是继续在入场侧加条件。

### 2.3 根因三：出场侧已经饱和并被反复证伪

`docs/backtest-optimization-design.md` §9 记录了完整的出场侧实验链：

- §9.5 的 `trail-activate-r` 五档 A/B 中，固定 R 门槛被证伪：0.5 档胜率升到 57.2%，但总收益降到 99.4%、回撤升到 17.3%，整体判据不通过；1.0 以上档位退化到 ATR 或时间止损，没有采纳价值。
- §9.6 至 §9.9 的时间阶梯前沿最终收敛到 `sched_4d_085`，宽度 0.80 至 0.85 构成平顶，结论对参数不敏感。
- §9.10 的三个切点验证只是子样本稳定性，不是样本外；参数本身是在包含这些切点的全 5 年样本上选的。
- §9.11 的 regime 自适应 trail 与个股级延续性条件化均被证伪，宽 trail 在所有分桶中都优于紧 trail，不存在支持切紧的桶。

计划 v2 的已证伪清单进一步覆盖了收紧 trail、武装前止损、跳空过滤、regime 硬开关、per-strategy exit、resonance-layered 等方向。出场搜索已经饱和，继续在全样本上调出场参数，最可能的结果是机械抬高胜率，同时牺牲风险调整后收益。

### 2.4 胜率为什么不能当裁判

胜率与出场机械耦合。放宽 trail 会把一部分小亏损转成时间止损或更大的亏损，账面胜率上升，但单笔亏损幅度和回撤可能同时恶化。§9.5 的 0.5 档就是典型：胜率 57.2%，总收益和回撤都不合格。

信号级胜率还是 18 条高度相关策略曲线的无权重平均，不是组合口径。用它做验收，会让优化偏向"多留一点浮盈就卖"的出场参数，而不是"在资金约束下把净值做高"的配置。

《指标契约》§2 因此把主指标定为资金约束下的样本外 CAGR，附加 maxDD ≤ 25% 与成交笔数 ≥ 100 的约束，期望与胜率的 bootstrap 95% CI 下界须大于 0，胜率仅作诊断。计划 v2 §9 的口径相同：目标不是胜率，而是资金约束下的样本外 CAGR。

## 3. 结论与决策

1. **唯一裁判是组合级样本外风险调整记分板。** 主指标为资金约束下的样本外 CAGR，同时报告夏普、最大回撤、成交笔数、现金占比和成本拖累。胜率只用于解释交易结构，不单独作为通过条件。
2. **度量契约只冻结度量口径。** 成本 0.35% 往返、T+1 盯市、PIT 宇宙、去簇共振定义、`next_open` 入场属于冻结项；`min_resonance_families` 属于实验参数，改动必须显式登记并改变 `config_hash`。
3. **家族共振 ≥1 是当前最强的已测杠杆，但仍需过门槛。** 消融已完成，卡 A 待池化样本外 Δ 的日期分块 bootstrap；通过后即可翻转，不重跑消融。
4. **新实验按卡 B 到卡 C 推进。** 先解决固定 1/N 预算导致的现金拖累，再测试并发信号选股与持仓上限排序。卡 D 的 `tushare_moneyflow` 分层因子优先级最低，基线稳定后再跑。
5. **不再调出场。** §9 已饱和或证伪的方向不重新开题，除非出现新的逐笔 capture 证据或新引擎能力。
6. **本阶段只交付诊断、方案和文档，不修改回测代码，不翻转任何默认值。**

## 4. 证据边界与未验证项

- **股票池仍是 L-only。** `s.list_status='L'` 会剔除窗口内退市股，PIT 池（T0.4）尚未完成，反转、涨停、小市值策略的表现可能仍被系统性抬高。
- **完整 WFO 引擎（T0.3）尚未完成。** 3.88% 与 8.19% 都是单一预热后的样本外口径，不是多年滚动 WFO。翻转门槛因此改用可构建的日期分块 bootstrap，而不是等一个尚不存在的 WFO。
- **消融不是 WFO 证据。** ≥1 家族的 8.19%、45.23%、10.48%、67.8% 来自同日同代码的全样本消融，只能作为卡 A 的先验，不能直接当作最终采纳依据。
- **5 日验证只能观测。** 计划 v2 §11.1 记录的策略验证胜率 27.9% 与全市场 base rate 27.0% 接近，不能作为决策或选参输入。
- **基线可复现性已修复。** 2026-10-18 修复 numexpr 2.14.1 污染后重跑，同一命令连跑两次，候选表、成交、权益 CSV 的 sha256 完全一致，指标逐位一致，`config_hash=5eea0519`。
- **一次完整回测约 1.5 小时。** 实验设计优先选择可逆、单变量的旋钮，避免一次性堆叠多个改动。
