# 0003. 翻转门槛用日期分块 bootstrap，而不是 WFO 折

- 状态: 已接受

## 背景

ADR 0001 把 `min_resonance_families` 从"冻结的契约常量"降为"已登记的实验参数"，并以**可构建**的
证据作为翻转门槛：池化样本外每信号 Δ 的日期分块 bootstrap 95% CI 在风险调整口径下不劣于基线。
但《指标契约》§8.1 的原始放行规则是 `CI 排除 0` **且** `≥5/8 折同号`——后者预设了一套 walk-forward
optimization（扩张窗、6 个月测试段、6 个月步长、purge/embargo）。本仓库当前**没有** WFO 引擎，
而 `docs/backtest-experiment-cards.md` §4.5 明确把完整 WFO 只保留给"改信号或改出场定义"的改动。
卡 A（`min_resonance_families` 2 → 1）属参数变更，如果照 §8.1 逐字执行，就会被一道建不出来的门槛
无限阻塞——这正是 ADR 0001 要避免的局面。

此外，§8.1 的观测单元 `(strategy, signal_date t, code)`、`next_open` 入场、净收益、实际持有 `h`
是可以直接落地的，问题只出在"折"这个前置结构，以及几条没说清的口径（估计量、块长取自哪一臂、
放行规则与"不劣于"的语义）。

## 决策

对参数与资金配置类变更（卡 A/B/C），放行门槛改为**池化样本外 Δ 的日期分块 bootstrap**，
不建 WFO，不造"折"。规格全文见 `docs/backtest-flip-gate-spec.md`。要点：

- **估计量**：Δ = 候选臂 OOS 信号净收益均值 − 基线臂均值；两臂各用**自己**的信号集，
  不做交集、不做逐日配对差、不用组合级比值。它是策略级每信号均值对比，不是配对处理效应。
- **重抽**：日期轴取两臂 OOS 信号日期并集；块长 `L = max(ceil(p99_b), ceil(p99_c))`（按持有 K 线根数，
  不设上限）；非环绕移动块，2000 次，**联合**作用于两臂；按信号笔数加权；CI 取 2.5/97.5 百分位。
- **判据**：`ci_low > 0`（优效性）+ 三个 δ=0 的**描述性方向护栏**（CAGR/Sharpe/maxDD 不劣于基线）
  + 绝对门槛（maxDD ≤ 25%、成交笔数 ≥ 100）。
- **随机性**：无 `--seed` 入口，seed 由 `gate_version`、两臂 `config_hash`、数据快照、OOS 窗口、`L`、
  重抽次数等**确定性派生**（`sha256 → PCG64`），使判决是输入与规格的纯函数。
- **预注册**：变体计数、主比较唯一性、跨卡多重性声明，全部在跑之前写定；任何规格改动都算新变体。
- 判决产物显式记录 `wfo: {required: false, folds: null, reason: ...}`，把 §8.1 的偏离摆在明面上，
  而不是静默跳过。

## 后果

- 已知更优的配置（≥1 家族）离采纳只差一道**可执行**的门槛，而不是一道建不出来的门槛。
- 门槛把"信号级疗效"（Δ 的 CI）与"组合级安全"（CAGR/Sharpe/maxDD 护栏）分开表述，
  与 ADR 0001 的度量分层一致：前者是统计主张，后者是硬约束。
- 代价是必须诚实标注三处：① δ=0 的护栏是**描述性**的，不是形式化非劣性；② `n_dates` 是重抽单元，
  有效独立块 ≈ `n_dates / L`，不能说成独立样本量；③ 每信号净收益是信号级路径收益，不是成交收益。
  任何一处含糊，门槛就会退化成"看起来有统计支撑"的背书。
- 门槛读的是**去簇**后的信号表（`n_families` 生效处），不是 `collapse_candidates` 按 `rank_score`
  选出的胜者表，也不是成交表；后两者各自叠加了一道与 `min_resonance_families` 无关的筛选。
  为此驱动侧新增一个**追加式**产物 `{stem}_signals.csv`，不改任何既有产物路径或列。
- 没有种子旋钮，也就没有"换种子直到 CI 排除 0"的钓鱼空间；变体计数与预注册记录把探索与确认分开。
- §8.1 的折条款对卡 A/B/C 标记为不适用，但**不删除**：改信号或改出场定义的改动仍应回到完整 WFO。
- 卡间族错误率未受控（全零假设下 4 张卡 ≈ 18.5%），该限制必须写进产物 `warnings`。

## 备选方案

- **照 §8.1 逐字执行，先建完整 WFO。** 否决。门槛当前不可构建，会把已知更优的配置无限期搁置；
  且对"只改一个参数"的变更而言，WFO 的选参结构是多余的。
- **伪折：把 OOS 等分 8 段做同号检查，冒充"≥5/8 折同号"。** 否决。这不是 WFO，只是时间分段的符号
  稳定性；冒充折会让偏离被掩盖。（可作为**非门禁**诊断保留，须预先注册切分方式。）
- **用逐日配对差估计 Δ。** 否决。基线在"仅候选有信号"的日期上是空的，配对会丢掉候选多出来的信号，
  或被迫补零，估量随之失真。
- **用组合级指标之差（如 CAGR 之差）及其 CI 作为主判据。** 否决。那是护栏端点；把资本约束带来的
  非线性塞进主判据，会让门槛变成对资金模型的间接检验，而不是对处理的检验。
- **两臂独立重抽。** 否决。忽略两臂共享信号带来的正相关，会高估 Δ 的方差、无谓地降低功效。
- **暴露 `--seed` 便于复现。** 否决。它同时是钓鱼旋钮；确定性派生 seed 已经保证了可复现。
- **发明一个非劣性 margin δ>0。** 否决。需求没给 δ，事后补一个 δ 等于把结论往有利方向移动；
  宁可标注为描述性护栏，把缺陷摆出来，让团队在跑之前决定要不要预注册 δ。
