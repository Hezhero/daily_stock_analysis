# 0002. 现金拖累根因 = 固定 1/N 仓位规则

- 状态: 已接受

## 背景

组合级回测最刺眼的数字不是收益偏低，而是**资金长期闲置**。在 0.35% 往返成本、T+1 逐日盯市、
≤10 仓、`next_open` 入场的冻结度量画像下，≥2 家族默认配置的闲置现金为 77.7%，对应 3.88%
样本外 CAGR、43.67% 胜率、13.11% 最大回撤、Sharpe 0.423。作为对照，信号级口径给出平均年化
28.7% 与平均夏普 4.68，但那是一个无限资金、逐策略取最优持有期的系统，两者不可比。

把 `min_resonance_families` 从 2 降到 1 的家族消融能改善指标（CAGR 8.19%、胜率 45.23%、
maxDD 10.48%），但闲置现金仍有 67.8%。也就是说，放宽共振门槛只释放了一小部分资金，**大头不是
信号太少，而是仓位规则本身**。

## 决策

68% 到 78% 的闲置现金拖累是**结构性**的，根因是固定 1/N 仓位规则：

```python
# scripts/portfolio_sim.py 约第 439 行
budget = min(equity_prev / cfg.max_positions, cash)
```

每个入场最多只拿"前一日权益 / 持仓上限"（1/10）作为预算，与当时真实可用的现金无关。当

- 信号在时间上成簇出现，
- 各持仓的退出日期交错，
- 部分时间槽位空着，

账户就会长期停留在"10 个槽位只用了一部分、剩余现金无处可去"的状态。1/N 规则对每个仓位一视同仁，
既不因为现金充裕而多部署，也不因为槽位已满而少部署，闲置现金因此是规则的内生结果，而不是执行
噪声或数据问题。

修复方向是**资金部署感知仓位**（实验卡 B）：根据真实可用的闲置现金与波动率目标决定单笔预算，而
不是机械地切 1/N。优先复用既有的 `_TARGET_VOL_ANNUAL` / `_MAX_LEVERAGE` 全局配置，不新增平行
实现；实验必须保持"部署金额 ≤ 可用现金、持仓数 ≤ 上限、`max_dd_floor_pct` 生效"三条不变量，并
在验收时改变 `config_hash`。

本决策不涉及本轮代码改动；方案与优先级记录在 `docs/specs/backtest_度量层重建/spec.md`
（卡 B 先于卡 C，卡 D 最低）。

## 后果

- 优化注意力从出场侧转到资金部署侧。出场参数已被多轮 A/B 反复证伪或饱和
  （`docs/backtest-optimization-design.md` §9），继续调出场不会解决 2/3 以上资金不工作的问题。
- 卡 B 的收益上限来自把闲置现金投入已有的高质量候选，而不是提高杠杆；它属于仓位结构改动，预期
  同时影响收益、回撤与换手，验收必须用风险调整口径而不是单看 CAGR。
- 波动率目标与杠杆上限会让部署额随市场波动变化，回撤路径可能比固定 1/N 更集中，`max_dd_floor_pct`
  与不变量测试是必要护栏。
- 卡 B 与卡 A 是两个独立的杠杆：卡 A 增加候选供给，卡 B 改善资金使用；消融后仍有 67.8% 闲置，
  说明只做卡 A 不够。
- 任何默认值改动都必须改变 `config_hash` 并在 handoff / `main.py` 同口径体现，否则回测改善不能
  转化为实盘行为。

## 备选方案

- **继续只调出场参数。** 否决。出场侧已饱和且被证伪，无法解释 77.7% 的闲置现金；把出场调得再好，
  没有投入的资金也不会产生收益。
- **简单提高 `max_positions`。** 否决。≤10 仓是冻结度量画像的一部分，提高它等于改口径；而且只要
  单笔预算仍是固定 1/N，规则本身的结构性问题没有消失，只是把分母换大。
- **只把 `min_resonance_families` 降到 1。** 不足以解决。消融已证明它能把闲置现金从 77.7% 降到
  67.8%，但仍有超过三分之二的资金闲置，属于卡片 A 的独立杠杆，不能替代卡 B。
- **直接上杠杆放大收益。** 否决。它不是闲置现金的根因修复，且会放大回撤；部署感知仓位应优先用
  现有现金，杠杆上限只作为约束而不是目标。
