# 0004. 卡 D 用 v1 信号级门槛裁决，暂不建 WFO

- 状态: 已接受（2026-10-24，用户显式授权）

## 背景

`docs/backtest-experiment-cards.md` §4.5 与 `docs/specs/backtest_度量层重建/spec.md` 把完整
walk-forward optimization（WFO）保留给"改信号或改出场定义"的改动，并明确本阶段**不做**完整
WFO 引擎（T0.3）。同一份文档又规定卡 D 只登记、不实现。

但 ticket 06 把卡 D 定义为 `ready-for-agent`，要求把 `tushare_moneyflow` 的超大单／大单净额
登记为新策略或过滤条件，并"经 02 门槛"。卡 D 一旦新增策略，信号集合就会变化，按上述规则
应走 WFO；而 WFO 不存在，于是这张票被一道**当前不可构建**的门槛卡住。

同时，v2 组合层估计量（ADR 0003 之后的 ticket 08）在其预注册里写明只适用于"信号集合相同、
资金或配置不同"的卡（`docs/backtest-flip-gate-spec.md` §9），因此也不能用来裁决卡 D。

v1 信号级估计量在构造上则**支持两臂信号集不同**：它明确"两臂各用自己信号集，不做交集限制，
因为候选多出来的信号正是被检验的处理"（`docs/backtest-flip-gate-spec.md` §2）。

## 决策

对卡 D 的这一次预注册主比较，允许使用 **v1 信号级日期分块 bootstrap 门槛**
（`--estimator signal`，默认路径），不建 WFO、不伪造折。约束如下：

- 只适用于卡 D 这一次主比较；不得据此把 v1 推广到其他改信号／出场的卡。
- 判决**不翻转任何默认值**。PASS 只说明"值得另开一张票讨论是否把因子纳入默认策略池"；
  FAIL 则保持因子默认关闭。采纳本身仍需独立后续动作。
- 判决产物由 `scripts/portfolio_gate.py` 生成，其 `wfo.reason` 是 v1 的通用文案，无法在
  不改哈希的前提下替换。因此**不以产物文案为授权依据**：本 ADR 与账本 §10.11 的标注为准，
  二者必须写明"WFO 延后至 T0.3，卡 D 由用户授权的 v1 信号级门槛裁决"。
- 卡 D 的因子默认关闭（`--enable-smart-money-flow` 显式 opt-in），因此即使判决为 PASS，
  生产默认消费路径在本票内也不改变。
- 因子只注册 `STRATEGIES` / `STRATEGY_MASKS` / `STRATEGY_FAMILY` 三个动态字典；模块级派生结构
  （`STRATEGY_ALLOWED_REGIMES`、`REGIME_ALL_WEATHER`、`CONFLUENCE_EXEMPT`、
  `DEFENSIVE_HALF_POS_STRATEGIES`、`STRATEGY_SCORE_FUNCS`）保持不含它。判决在这套语义下测得，
  事后不得为了"补齐一致性"回写这些集合——那会改变被测的处理，属于未预注册变体。
- 一旦 T0.3 的 WFO 引擎落地，任何"把该因子纳入默认策略池"的决定都必须先用 WFO 重跑；
  本 ADR 不构成对该要求的豁免。

## 后果

- 卡 D 从"被不存在的 WFO 无限期阻塞"变成一次可执行、可复现、可审计的预注册比较。
- 估计量语义必须诚实标注：它是**策略级每信号均值对比**，不是配对处理效应，也不是组合层
  CAGR 效应。新增策略会改变同日共振/去簇结构，因此两臂不是同一信号集上的配对实验。
- 主判据仍是 `ci_low > 0`，护栏仍是 §4 的五项（δ=0 描述性方向护栏 + 绝对门槛），不放宽。
- 选择偏倚未消除：本因子此前在信号级（非 PIT、旧入场口径）已被测出 37.8% 胜率并移出注册表
  （`docs/backtest-optimization-roadmap.md`），本次是同一假设在新度量口径下的**唯一一次**
  预注册重测；变体计数从 1 起算，不允许按结果换阈值或换因子定义再试。
- 跨卡族错误率仍未受控；本卡使已测卡数从 3 增至 4，该限制继续写入产物 `warnings`。

## 备选方案

- **先建完整 WFO 再裁决卡 D。** 否决。WFO 属 T0.3，本阶段明确不做；用它做前置条件等于
  让卡 D 无限期悬空。
- **用 v2 组合层估计量裁决卡 D。** 否决。v2 的预注册边界明确排除"信号集合变化"的卡，
  越界使用属于未预注册的口径切换。
- **把卡 D 登记为"已由 P2-9 证伪"直接关闭。** 否决。P2-9 是旧口径（信号级、非 PIT、
  旧入场时点）下的胜率结论，不能替代当前冻结度量口径下的裁决；但它是本次比较的先验，
  必须写进预注册。
- **把因子做成"只改仓位/排序"的卡以套用 v2。** 否决。那会改变被检验的处理，属于偷换假设。
