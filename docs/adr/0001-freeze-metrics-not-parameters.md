# 0001. 冻结度量而非参数

- 状态: 已接受

## 背景

这套 5 年多策略回测长期存在两套互相打架的记分板。信号级口径给出平均胜率 55.6%、平均总收益
322%、平均年化 28.7%、平均夏普 4.68；受资金约束的组合级口径只有 3.88% 的样本外 CAGR、43.67%
胜率、13.11% 最大回撤、Sharpe 0.423，并且 77.7% 的资金长期闲置。前者衡量的是一个"信号级、
无限资金、逐策略取最优持有期"的系统，实物上无法照此下单。优化决策如果继续建立在前者之上，等于
在测一个并不存在的系统。

更麻烦的是旧《指标契约》§2.1 的冻结方式。它把 `min_resonance_families = 2` 与成本、盯市等
测量约定一起锁死，`_portfolio_sim_config()` 发现该值非 2 就抛 `RuntimeError`。但同一批工作给出的
家族消融显示，`min_resonance_families = 1` 在四项指标上全面更优：CAGR 8.19%（对 3.88%）、
胜率 45.23%（对 43.67%）、maxDD 10.48%（对 13.11%）、闲置现金 67.8%（对 77.7%）。一个可部署
参数被当成度量基准冻结，导致"要么测的不是真正在跑的系统，要么自相矛盾"。

## 决策

度量契约只冻结**度量口径**，不冻结可部署参数。冻结项包括：

- 成本：0.35% 往返（入场 / 出场各半），外加按 ADV 分档的单边滑点；
- 盯市：T+1，逐日收盘盯市，持有期内路径计入净值与回撤；
- 股票池：PIT 宇宙，纳入窗口内曾上市与后续退市的股票；
- 去簇共振：同日同股按不同家族去重计数，趋势簇上限 3、行业上限 2；
- 入场：`next_open`，跳空穿透成交。

`min_resonance_families` **不是**冻结的契约常量，而是已登记的实验参数。它可以被改动，但必须走
实验卡流程，并以**可构建**的证据作为翻转门槛：池化样本外每信号 Δ 的日期分块 bootstrap 95% CI
在风险调整口径（CAGR / Sharpe / maxDD）下不劣于基线。当前卡 A 的消融已完成，只差这道门槛。
门槛有意不要求先建出完整 WFO；WFO 保留给改信号或改出场定义的改动。

配套的守卫语义同步调整：`_portfolio_sim_config()` 从"`min_resonance_families` 必须等于 2"
改为"`SimConfig` 默认值必须匹配冻结度量画像；已登记的实验参数允许显式覆盖，覆盖时打出 warning
并改变 `config_hash`"。默认值仍保持 2，未经登记的静默调参仍然被拒绝。

本决策的事实与边界记录在 `docs/specs/backtest_度量层重建/spec.md`（状态：已定稿，Round 1 与
Round 2 均已锁定），度量定义以该 spec 与 `result/指标契约_metric_contract_v1_20261017.md` 为准。

## 后果

- 度量层与实验层被分开：改口径需要走契约修订，改可部署参数只需登记实验卡，两类变更不再互相绑架。
- 已发布基线保持可复现。默认值不变，`config_hash` 仍是
  `5eea05195af3d89432af8b2a049fde2517d6a53b`；只有显式覆盖才会换哈希。
- `min_resonance_families` 的解冻让已知最强杠杆（≥1 家族）离采纳只差一道可执行的门槛，而不是被
  一个建不出来的 WFO 无限阻塞。
- 代价是守卫不再"一个数字卡死"。`_portfolio_sim_config()` 必须真正校验整张度量画像，测试也要覆盖
  "实验覆盖改哈希 + 告警"与"画像不符则 `RuntimeError`"两条路径，否则解冻会退化成无约束调参。
- 任何默认值改动仍须在 handoff 与 `main.py` 同口径体现，否则回测与实盘会再次分叉。
- numexpr 2.14.1 的多线程缺陷曾污染 T0.1 基线与家族消融，回测进程已关闭 `compute.use_numexpr`；
  本决策依赖的消融数字以修复后重跑结果为准。

## 备选方案

- **继续冻结 `min_resonance_families = 2`。** 否决。它把可部署参数误当度量基准，且与当日消融证据
  直接冲突，会让所有优化决策建立在矛盾证据上。
- **取消契约，什么都不冻结。** 否决。没有统一口径就无法比较实验，也无法防止静默调参；冻结度量
  正是为了给实验提供稳定裁判。
- **要求先建出完整 WFO 才允许翻转默认值。** 否决。该门槛当前不可构建，会把已知更优的配置无限期
  搁置；分块 bootstrap 已能对池化样本外 Δ 给出风险调整后的统计判断。
- **只把 `min_resonance_families` 改成 1，不调整契约语义。** 否决。单点改默认值绕过了登记与证据
  门槛，下一次其他参数也会以同样方式被悄悄改掉。
