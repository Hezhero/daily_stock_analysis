## 0. 登记规则

本文件把下一阶段的回测改动登记为四张实验卡。每张卡只回答一个问题，只改一个可逆变量，并预先写死判据与回滚方式。

**本阶段交付 = 诊断 + 方案 + 文档；不修改回测代码。** 下文每张卡的"改动点"都是未来改动，本轮不执行。

统一裁判为组合级样本外风险调整记分板：

- 主指标：资金约束下的样本外 CAGR。
- 附加约束：最大回撤 ≤ 25%，成交笔数 ≥ 100。
- 次指标：全历日夏普、每笔期望、换手、容量、平均现金占比、成本拖累。
- 胜率仅作诊断，不单独作为通过条件。
- 任何实验参数改动都必须改变 `config_hash`，并写入侧边产物；不允许静默调参。

## 2. 逐卡说明

### 2.1 卡 A：`min_resonance_families = 1`

**假设。** 当前 ≥2 家族的默认值把大量合格信号挡在门外，导致平均持仓只有 2.23、现金占比 77.7%。放宽到 ≥1 家族后，成交增加、资金占用上升，组合级 CAGR、夏普、最大回撤和胜率应同时改善。

**依据。** 2026-10-18 的消融已完成，两臂同代码同数据，信号生成阶段完全一致（raw 18517、build 17915、各策略信号数逐项相同），差异只来自家族过滤：

| 指标 | ≥2 家族 | ≥1 家族 |
| --- | ---: | ---: |
| CAGR | 3.88% | 8.19% |
| 胜率 | 43.67% | 45.23% |
| 最大回撤 | 13.11% | 10.48% |
| 闲置现金 | 77.7% | 67.8% |
| 夏普 | 0.423 | 0.719 |
| 成交笔数 | 561 | 838 |
| 总收益 | 22.12% | 154.74% |
| 平均持仓数 | 2.23 | 3.22 |
| 成本拖累 | 51.35% | 75.27% |

**改动点（未来）。** 把 `min_resonance_families` 从度量契约的冻结常量降为实验参数。实验运行时显式覆盖为 1，触发契约守卫的告警并改变 `config_hash`。冻结的成本、盯市、PIT、去簇共振定义和 `next_open` 入场口径保持不变。

**判据。** 消融结果只是全样本加单一预热后样本外口径，不是完整 WFO。翻转前必须通过池化样本外每信号 Δ 的日期分块 bootstrap CI，且 CAGR、夏普、最大回撤三项风险调整口径不劣于基线。成交增加带来的成本拖累必须计入，不能用毛收益比较。

**回滚。** 把 `min_resonance_families` 恢复为 2，`config_hash` 随之变化，新旧结果并列输出。回滚不删除旧代码路径，也不覆盖历史产物。

**风险与边界。** 成交从 561 增至 838，换手和成本拖累明显上升，容量与滑点假设需要一并报告。若 bootstrap 门槛不通过，保留 ≥2 默认，不继续在 2 与 3 之间扫参，避免把一次预注册实验变成参数搜索。

**状态。** 门槛判决已出：**不通过**（2026-10-21）。每信号净收益 Δ = +0.115%，95% CI [−0.059%, +0.304%] 含 0（`L=9`、`B=2000`、`n_dates=332`、`tested_count=1`），主判据 `ci_excludes_zero` 不过；组合护栏杆全部改善（CAGR 4.20%→7.48%、Sharpe 0.444→0.677、maxDD 13.91%→10.48%、成交 560→829）但不得替代主判据。默认值保持 `min_resonance_families = 2`，不重跑消融，不在 2 与 3 之间扫参。证书见账本 `docs/backtest-optimization-design.md` §10.5，细节见 ticket 03。

### 2.2 卡 B：资金部署感知仓位

**假设。** 现金拖累的主要来源不是信号数量，而是固定 1/N 的仓位预算。把预算改为资金部署感知规则后，组合可以在不突破最大回撤约束的前提下提高资金占用和 CAGR。

**依据。** `scripts/portfolio_sim.py` 的 `_entry_budget()`（`fixed_1n` 分支）为 `budget = min(equity_prev / cfg.max_positions, cash)`，`max_positions` 默认 10。每笔新仓位最多拿到前一日权益的十分之一，与信号质量、波动率和可用现金无关。平均持仓 2.23、平均现金占比 77.70%，与这条规则直接一致。即使家族门槛降到 ≥1，闲置现金仍有 67.8%，说明单靠放宽共振不足以解决部署问题。

**改动点（v1 已实现）。** `SimConfig` 新增 `size_mode` / `target_positions` / `cash_buffer_pct`，`_entry_budget()` 在 `deploy_aware` 下按 `max(0, min(equity_prev / target_positions, cash − cash_buffer_pct · equity_prev))` 计算单笔预算。三项处于默认值时不进入 `config_hash`，`fixed_1n` 下拒绝非默认值，避免"改了哈希但行为不变"。v1 未启用波动率目标缩放（`_TARGET_VOL_ANNUAL` 保持 0.0），`_MAX_LEVERAGE` 保持 1.0，不引入杠杆。

**不变量。** 按 spec 的 Testing Decisions 执行：

- 部署金额不超过可用现金。
- 持仓数不超过 `max_positions`。
- `max_dd_floor_pct` 生效。
- 任何参数改动改变 `config_hash`，并保持结果确定性。

**判据。** 池化样本外每信号 Δ 的日期分块 bootstrap CI 通过；CAGR 高于基线，夏普与最大回撤不劣于基线；平均现金占比下降，但换手、成本拖累和容量变化必须一并报告。若 CAGR 上升但最大回撤突破 25%，判为不通过，不用"收益更高"抵消回撤恶化。

**回滚。** 关闭部署感知开关，恢复固定 1/N 预算；`config_hash` 随参数变化；旧预算路径保留，结果并列输出。

**风险与边界。** 提高资金占用会放大回撤和集中度，T+1 下的现金缓冲也不能压到零。杠杆不属于本卡的第一版范围；若未来要测试杠杆，应单独登记为变体，不能混在卡 B 里悄悄打开。

**状态。** **门槛判决不通过（2026-10-21），默认保持 `fixed_1n`。** 预注册规则 `deploy_aware` / `target_positions=5` / `cash_buffer_pct=0.05` 只跑一次：CAGR 4.20% → 5.82%、Sharpe 0.444 → 0.473 改善，但最大回撤 13.91% → **16.82%** 劣化（`maxdd_non_inferior` 驳回）；资金占用只从 22.3% 升到 26.9%，持仓反而更集中（2.23 → 1.77 只）。另一项驳回 `ci_excludes_zero` 是估计量退化：门禁比较信号级净收益均值差，而卡 B 两臂 `signals.csv` 逐字节相同（sha256 `2A5DB331…`），Δ 构造上恒为 0 —— **该估计量无法裁决纯资金管理卡**，但不得在看过结果后换口径翻案。详见账本 §10.7（预注册）与 §10.8（判决）。卡 A 判决（§10.5：不通过）不阻塞本卡，原"卡 A 过门槛后启动"只是排序约定，已在账本 §10.6 改回排序语义。换手 112.63 → 134.60、成本拖累 51.35% → 61.99% 均已随判决报告；容量无独立指标，未单独量化。

### 2.3 卡 C：并发信号选股与持仓上限排序

**假设。** 在 ≤10 仓约束下，同日并发信号超过可用仓位时，选择顺序会直接影响组合结果。按去簇共振加期望排序取 TopN，并保留趋势簇 ≤3、行业 ≤2 的上限，可以改善组合级 CAGR 与夏普。

**依据。** 计划 v2 §5 的 Card A 把"资金约束下的同时信号选股"列为唯一未被测试、先验中高的杠杆。它改变的是资金配置，不是信号本身，因此不属于数据挖掘式的新因子搜索。当前《指标契约》§3 已把"去簇共振加期望 TopN、趋势簇 ≤3、行业 ≤2"写进测量层的排序规则；卡 C 是在此基础上登记的选择顺序变体，必须按契约要求单独计数，不能静默改规则。

**改动点（已落地）。** 同日并发信号选股、`max_positions=10`、`family_cap={trend:3}`、`industry_cap=2` 与候选排序 `lead_exp↓ → n_families↓ → strength↓ → code↑ → strategy↑` 已在 `scripts/portfolio_sim.py` 运行；本卡唯一改动是**对调前两位排序键**（`n_families↓` 优先），由 `SimConfig.rank_mode` / `--portfolio-sim-rank-mode` 驱动，后四位键、`mergesort`、`na_position` 与全部上限不变，不新增每日开仓闸门。度量口径、成本、盯市、PIT 和入场方式不变。排序规则在开跑前写死，未按结果调整。

**判据。** 与卡 A、卡 B 相同的 bootstrap 门槛；组合 CAGR、夏普、最大回撤不劣于基线；成交笔数 ≥100；报告平均现金占比、换手和成本拖累。若选择顺序的改善只存在于个别年份或个别 regime，不采纳，避免把样本内噪声当成规则。

**回滚。** 恢复契约冻结的排序规则；`config_hash` 随规则变化；新旧结果并列输出。

**风险与边界。** 排序规则自带选择自由度，容易在反复试错中过拟合。卡 C 必须在开跑前固定规则、记录变体数，并且只做一次主比较；不接受"看过结果再换排序键"的迭代。与卡 B 共享同一套资金约束基础设施，但两张卡分开跑，避免同时改动仓位预算和选择顺序导致归因不清。

**状态。** **门槛判决不通过（2026-10-24），默认保持 `lead_exp_first`。** 预注册的单次主比较（只对调前两位排序键，`rank_mode=resonance_first`）两臂各跑一次：CAGR 4.203% → 5.581%、Sharpe 0.4442 → 0.5623、最大回撤 13.907% → 13.579%、成交 560 → 558，五项护栏（`cagr_non_inferior`、`sharpe_non_inferior`、`maxdd_non_inferior`、`maxdd_cap`、`min_trades`）全过，但主判据 `ci_excludes_zero` 不过：ΔCAGR = +1.377pct，95% CI [−0.883%, +3.909%]，下界未过零（`L=21`、`B=2000`、`n_dates=1148`、`se=1.231`、`tested_count=1`）。两臂 `signals.csv` sha256 逐字节相同（`2A5DB331…`），漏斗除 `filled` 560 → 558 外全同，说明改动只落在 collapse 之后的同日排序竞争。年度收益差 2022 +6.40、2023 −2.32、2024 +2.03、2025 +0.37、2026 −0.28（pct，描述性），改善并非全期一致。不翻转默认值、不扫第三种排序、不改判据。详见账本 §10.10 与 ticket 05 判决节；`resonance_first` 仅保留为显式 CLI 开关。

### 2.4 卡 D：`tushare_moneyflow` 分层主力资金因子

**假设。** `tushare_moneyflow` 已提供超大单、大单、中单、小单的买卖分层字段，当前只使用了 `net_mf_amount`。把大单与超大单的净流入纳入因子，可能提供与现有技术信号、龙虎榜信号不同的增量信息。

**依据。** `docs/backtest-optimization-design.md` §4.3 已记录该表的分层字段和"已 JOIN 但未使用分层字段"的状态。按 spec 的 Round 2 决策，新因子登记为低优先级卡 D：它没有经过验证，数据加工和策略注册的成本高于卡 A、卡 B、卡 C，先验也最低。

**改动点（未来）。** 扩展 `load_data()` 的 SQL SELECT，读取 `buy_lg_amount`、`sell_lg_amount`、`buy_elg_amount`、`sell_elg_amount` 等分层字段，构造大单加超大单净额。因子可以登记为新策略或作为既有策略的过滤条件，复用现有策略注册与数据转换入口，不新增平行实现。第一版只做增量检验，不改生产默认。

**判据。** 与卡 A、卡 B、卡 C 相同的 bootstrap 门槛；相对现有 `net_mf_amount` 必须有增量贡献，不能只是重复已有资金流信息；与 `inst_smart_break` 的相关性检查通过；报告分层字段的覆盖率与缺失处理。只有在基线稳定后才允许开跑。

**回滚。** 移除因子或关闭开关；不进入生产消费路径；旧数据路径与旧策略保持可运行。

**风险与边界。** 分层资金流可能存在字段缺失、口径变更和行业分布偏差，且与既有资金流因子高度相关。卡 D 不抢在卡 A、卡 B、卡 C 之前，避免在基线尚未稳定时引入新的数据质量问题。

**状态。** **门槛判决不通过（2026-10-24），因子保持默认关闭。** 在 ADR 0004 授权下用 v1 信号级门槛做了一次预注册主比较（改信号本应走 WFO，T0.3 未落地）：基线 CAGR 4.203% / Sharpe 0.4442 / 最大回撤 13.907% / 成交 560，候选 6.480% / 0.6106 / 14.034% / 568。`cagr_non_inferior`、`sharpe_non_inferior`、`maxdd_cap`、`min_trades` 通过，但主判据 `ci_excludes_zero` 不过（Δ = +0.008pct，95% CI [−0.023%, +0.036%]）且 `maxdd_non_inferior` 不过（14.034% > 13.907%）。与 `inst_smart_break` 的原始信号 Jaccard 0.041、Pearson r 0.061，不是重复信息；但组合层改善来自信号结构而非每信号期望。不采纳、不翻默认、不扫因子变体；任何后续采纳须等 WFO。详见账本 §10.11 与 ticket 06 判决节。

## 3. 锁定优先级

1. **卡 A 先行。** 消融已完成，是当前最强的已测杠杆。过 bootstrap 门槛即可翻转，不重跑消融，不继续扫家族门槛。
2. **新实验按卡 B 到卡 C 的顺序推进。** 先修现金拖累的结构性根因，再测试并发信号的选择顺序。两张卡共享资金约束基础设施，但分开跑，保证归因清晰。
3. **卡 D 最低。** 基线稳定后再跑，不与前三张卡并行抢占验证预算。

这个顺序来自 Round 2 的锁定决策：卡 A 是已测待门槛，卡 B 直击 77.7% 现金闲置的根因，卡 C 是计划书原本的首推方向，卡 D 是未验证的新因子。

## 4. 翻转门槛

任何卡要改变默认值，必须同时满足：

1. **池化样本外每信号 Δ。** 观测单元为 `(strategy, signal_date, code)`，使用 `next_open` 入场和扣成本后的净收益，记录实际持有期。不平均各折指标，直接池化样本外信号。
2. **日期分块 bootstrap CI。** 按 date 做 moving-block bootstrap，block 取实际持有期的 99 分位，重采样 2000 次，有效样本为 `n_dates` 而不是信号笔数。95% CI 必须排除 0。
3. **风险调整口径不劣于基线。** CAGR 不低于基线，夏普不低于基线，最大回撤不高于基线；同时满足 maxDD ≤25% 与成交笔数 ≥100。CAGR 单独上升但夏普或回撤恶化的，不算通过。
4. **变体计数。** 记录已测变体数，防止数据窥探。每张卡只做一次预注册主比较，不按结果反复换参数。
5. **完整 WFO 只保留给改信号或出场定义的改动。** 卡 A、卡 B、卡 C 属于参数或资金配置改动，走上述 bootstrap 门槛，不被尚不存在的完整 WFO 引擎无限阻塞。卡 D 若最终改变信号定义，再按契约 §8.1 补 WFO 口径。

门槛不通过时保留默认值，记录失败原因，不追加局部 patch，不把同一张卡拆成多轮小修继续试。

## 5. 交付边界
