## 1. 目的与冻结范围

本契约只解决一件事：让回测、WFO 与实盘决策看到同一个系统。范围限定为测量层与指标口径，不含任何策略参数调整和收益承诺。

在以下口径同时成立前，任何"提升"结论不得进入验收：

1. PIT 股票池（T0.4）；
2. 0.35% 成本档（T0.1）；
3. 资金约束（≤10 仓、T+1、逐日盯市，T0.1）；
4. 样本外（T0.3、T0.6）。

冻结期内，旧指标只作参考，不作决策依据。需要先行失效的旧数字：`322%`、`8.4% DD`、`4.68 Sharpe`、`38.7%`、`1.59`、`+19.2%`。

## 2. 主指标定义

**唯一主指标：资金约束下的样本外 CAGR。**

- 计算基础：T0.1 模拟器输出的完整净值曲线。
- 附加约束：**maxDD ≤ 25%** + **成交笔数 ≥ 100**（均于 2026-10-17 批准冻结，见 §2.1）。
- **胜率仅作诊断**，不得单独作为通过条件。
- 期望与胜率的 **bootstrap 95% CI 下界须 > 0**。
- 旧指标（平均 sleeve 收益、平均 sleeve 回撤、单笔胜率）降级为参考，不进入验收。

### 2.1 冻结度量画像与已登记实验参数（2026-10-17 批准；2026-10-19 修订）

**冻结度量画像（度量口径与验收门槛）**：决定"测的是什么"。以下任一项改动都会改变度量基准，属契约变更（须走 ADR），不得静默调参；代码守卫见 `scripts/backtest_5y_23strategies.py::_portfolio_sim_config()` 的 `_METRIC_PROFILE_*`。

| 参数 | 冻结值 | 说明 |
| --- | --- | --- |
| 显式成本 | **0.35% 往返**（入场/出场各半） | 与现有 `TRADING_COST_PCT` 每笔减一次的往返口径一致 |
| 滑点 | **ADV 分档、单边** | ADV≥10亿 5bp；3–10亿 10bp；1–3亿 20bp；0.3–1亿 35bp；<0.3亿 50bp；ADV=`amount` 20 日均值（元） |
| OOS 窗口 | **252 交易日预热后至期末全曲线** | `oos_start = cal[min(252, n-1)]`；主指标 CAGR 在该窗口计算，另报全期 CAGR |
| maxDD 下限 | **≤ 25%** | 验收门槛 |
| 最小成交笔数 | **≥ 100 笔** | 验收门槛，不足记 `insufficient_trades` |
| 去簇共振定义 | **家族去重** | 固定 4 家族 trend/reversal/limitup/fundamental；同日同股同家族只计一次 |

**已登记实验参数**：默认值仍被守卫（`SimConfig` 默认值必须等于登记值），但不是度量基准，允许经相应登记路径覆盖；覆盖 = warning + `config_hash` 改变 = 一次"已登记的重跑"。其中持仓上限 / 最大持有 / 持仓簇上限 / 行业上限属**部署/选取旋钮**（实验卡 B/C 的靶子）。

| 参数 | 登记默认值 | 覆盖方式与语义 |
| --- | --- | --- |
| `min_resonance_families` | **2** | 4 家族中同日同股至少命中的不同家族数；经 `--portfolio-sim-min-families` 显式覆盖（代码守卫 `_REGISTERED_EXPERIMENT_DEFAULTS`），覆盖 = warning + `config_hash` 改变 |
| 持仓上限 `max_positions` | **10** | 已登记默认值；覆盖须走相应登记路径（附 warning 并改变 `config_hash`） |
| 最大持有 `max_holding_bars` | **10** | 已登记默认值；覆盖须走相应登记路径（附 warning 并改变 `config_hash`） |
| 持仓簇上限 `family_cap` | **trend ≤ 3** | 已登记默认值（`_REGISTERED_EXPERIMENT_FAMILY_CAP`）；覆盖须走相应登记路径（附 warning 并改变 `config_hash`） |
| 行业上限 `industry_cap` | **2** | 已登记默认值；覆盖须走相应登记路径（附 warning 并改变 `config_hash`） |

> 去簇共振的**定义**（4 家族、同日同股同家族只计一次）属冻结度量画像；`≥N 家族` 的**阈值**属已登记实验参数 `min_resonance_families`，两者不得混为一谈。
>
> 上述参数写入 `SimConfig` 并计入 `config_hash`。守卫区分两类变更：`_METRIC_PROFILE_*` 不符 → `RuntimeError`（契约变更，须走 ADR）；已登记实验参数默认值不符 → 同样 `RuntimeError`，显式登记覆盖 → warning + `config_hash` 改变（已登记重跑）。

## 3. 模拟器规格（T0.1）

建立**资金约束 + 逐日盯市**组合模拟器，作为唯一 headline 来源。

| 项目 | 规格 |
| --- | --- |
| 账户 | 单一账户；初始资金固定 |
| 持仓上限 | **≤10 仓** |
| 空仓 | 现金空仓 |
| 交易约束 | **T+1（入场日不可卖）** |
| 入场 | `next_open` |
| 成本 | **0.35% + 按 ADV 分档滑点** |
| 成交 | **跳空穿透成交** |
| 盯市 | **每日收盘盯市，含持仓内路径** |
| 输出 | **完整净值曲线** |
| 排序/选取 | 规则写死防调参：**去簇共振 + 期望 TopN**；**簇上限趋势≤3**；**行业≤2** |

排序与选取的**机制**（去簇共振 + 期望 TopN 排序）属测量层冻结项，不得在实验过程中改动；其**旋钮**（持仓上限 / 簇上限 / 行业上限 / 最大持有）属已登记实验参数，改动须走相应登记路径并计入 `config_hash`。任何规则变更须单独登记为实验变体，并计入 T0.6 的已测变体数。

## 8. 显著性护栏（T0.6）

- 期望/胜率报告 **bootstrap CI**。
- **记录已测变体数**，防止数据窥探。
- **有效样本 = n_dates**，不是信号笔数。
- WFO 统计规范全文见 §8.1。

### 8.1 WFO 统计规范

- 观测单元：`(strategy, signal_date t, code)`，`next_open` 入场，净收益（扣成本），并记录实际持有 `h`。
- 折叠：扩张窗、6 个月 test、6 个月 step、最少 24 个月 train → 约 8 折（覆盖 2023-01..2026-09）。
- purge/embargo：`h_max` = 实际持有 99 分位（10–15 交易日），丢弃每折 train 尾部 `h_max`。
- 样本内选参：每折只用 train 选持有期 + 出场档 + 策略排序；报 Arm A（折内选参）vs Arm B（固定 4d_085/5d）。
- 估计：**池化 OOS 信号**（不平均折指标）；报 n_signals、**n_dates**、n_folds、逐折 min/median/max。
- 置信区间：**按 date 的 moving-block bootstrap**（block = h_max，2000 次）；**有效样本 = n_dates**。
- 预注册放行规则：仅当 OOS 池化 Δ 的 95% date-block CI 排除 0 **且** ≥5/8 折同号，才允许改默认。
- H2（宽/紧 trail 的 regime 依赖）正确检验：**同信号配对** Δ、date-clustered SE、OOS；池化样本内分组均值与 3 日窗都不能裁决。

## 9. 5 日验证降级（仅观测）

### 9.1 实证

在 2026-09-21..2026-09-23 验证窗（3 个入场日）上做全市场 base-rate 对照（数据源：tushare_daily / tushare_stock_basic / tushare_stk_limit / tushare_index_daily / tushare_trade_cal / tushare_adj_factor，复用 `_get_pg_engine()`）：

- 交易日历确认：09-18/21/22/23/24/28/29/30、10-08/09/12/13/14/15/16（休 09-25、10-01..10-07）；入场 09-21→09-22 open、09-22→09-23、09-23→09-24。
- 全 A（+5d 收盘）：胜率 **26.99%**（净 0.15% 成本 26.41%），平均收益 −3.58%；+3d 20.78%；+10d 15.67%；+4d（回测 5-bar 口径）23.13%。
- 策略池口径（SSE/SZSE 主板+中小板+创业板、上市≥120d、成交额≥5e6）：+5d **29.23% 毛 / 28.60% 净**；+4d 24.70%。
- CSI300 同窗：+3d −4.21%、+5d −4.64%、+10d −7.80%。
- 策略验证整体胜率 = 24/86 = **27.9%**。

### 9.2 结论

5 日验证胜率（27.9%）≈ 全市场 base rate（27.0%/策略池 29.2%），且回测口径下策略（27.9%）高于随机 base rate（23.1%）而市场同期 −4.64%。→ 5 日验证**只能作观测，禁止作为决策/选参输入**。

### 9.3 数据质量（如实记录）

缺失出场价 8/19/15 笔；一字涨停剔除 17；0.00% 平价 188/174/73；adj_factor 敏感性仅 +0.2~0.3pp。

## 11. 验收与回滚

### 11.1 验收

- 全部以**并列输出**实现：新口径为新列/新报告，旧数字仍可复现。
- 不覆盖、不删旧路径。
- 验收必须同时报告：**池口径（PIT/L-only）+ 成本档 + 成交价假设 + 是否 OOS**。
- 主指标为资金约束 OOS CAGR，且满足 maxDD 下限、最小成交笔数、bootstrap 95% CI 下界 > 0。

### 11.2 纪律

任一"提升"若在 **PIT + 0.35% 成本 + 资金约束 + OOS** 四重口径下不成立，即视为证伪，记入 v2 文档 §7 的已证伪清单。

### 11.3 回滚

- 新模拟器、新会计口径、PIT 池、capture 修正均以新列/新报告并列存在。
- 需要回滚时停止消费新列/新报告即可，旧路径保持可运行。
- 不通过删除旧代码实现回滚。
